# SOFAR LSW3 Cloud Bridge

This service is the first cloud receiver for an LSW3 logger configured to send Server B traffic to a custom TCP endpoint.

- Listens on Railway's `PORT` environment variable.
- Replies to the LSW3 startup frame using the known Server-B response format.
- Stores raw V5 frames in Supabase table `solar_frames`.
- Server A/SOLARMAN settings should remain unchanged during testing.

## Required Railway variables

`SUPABASE_URL` = your Supabase project URL

`SUPABASE_KEY` = a server-side Supabase key. Do not expose this key in frontend code.

## Supabase table

```sql
create table public.solar_frames (
  id bigint generated by default as identity primary key,
  received_at timestamptz not null,
  length integer not null,
  hex text not null,
  control_code integer,
  sequence integer,
  logger_serial bigint
);
```

After the first successful LSW3 connection, the raw frames will be inspected and the telemetry decoder will be added for this exact logger firmware/model.
